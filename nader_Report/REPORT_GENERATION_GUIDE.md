# Report Generation Guide\n\n**Author:** Nader Nikbakht (nikbakht@mit.edu)  \n**Date:** January 2025  \n\n## 🎯 Quick Reference\n\nThis guide explains how to regenerate the comprehensive Neural Data Exploration report.\n\n## 📋 What Gets Generated\n\n### Reports\n- **`Neural_Data_Exploration_Report.html`** - Interactive HTML report with embedded figures\n- **`Neural_Data_Exploration_Findings_Report.md`** - Detailed markdown report\n- **`README_Report.md`** - Package documentation\n\n### Key Figures\n- **`neural_features_trial_1.png`** - Neural feature extraction example\n- **`target_comparison_per_channel.png`** - Target comparison analysis\n- **`individual_channel_psth_by_target.png`** - Individual channel PSTH\n- **`aligned_psth_dtw_comparison.png`** - DTW alignment comparison\n- **`figures/`** - Individual condition plots (27 files)\n\n## 🚀 How to Regenerate\n\n### Option 1: Automated Script (Recommended)\n```bash\npython generate_report.py\n```\n\n### Option 2: Manual Steps\n\n1. **Generate Analysis Figures:**\n   ```bash\n   python aligned_psth.py\n   python individual_channel_psth_by_target.py\n   python neural_feature_extraction.py\n   ```\n\n2. **Create Report Folder:**\n   ```bash\n   mkdir nader_Report\n   mkdir nader_Report\\figures\n   ```\n\n3. **Copy Files:**\n   ```bash\n   copy *.md nader_Report\\\n   copy *.py nader_Report\\\n   copy *.ipynb nader_Report\\\n   copy *.csv nader_Report\\\n   copy *.png nader_Report\\\n   copy *.html nader_Report\\\n   xcopy utils nader_Report\\utils\\ /E /I\n   xcopy figures nader_Report\\figures\\ /E /I\n   ```\n\n4. **Update HTML Report:**\n   - Edit `Neural_Data_Exploration_Report.html`\n   - Ensure figure paths are correct\n   - Add any new analysis results\n\n## 📊 Key Analysis Scripts\n\n### Core Processing\n- **`precise_time_alignment.py`** - Main data integration\n- **`neural_feature_extraction.py`** - Feature extraction pipeline\n\n### Analysis Notebooks\n- **`behavioral_feature_exploration.ipynb`** - Behavioral analysis\n- **`neural_feature_exploration.ipynb`** - Neural feature analysis\n- **`target_psth_analysis.ipynb`** - PSTH analysis\n- **`decoding_exploration.ipynb`** - Ridge regression decoding\n\n### Visualization Scripts\n- **`aligned_psth.py`** - DTW alignment analysis (generates 28 figures)\n- **`individual_channel_psth_by_target.py`** - Individual channel analysis\n\n## 🔧 Dependencies\n\nEnsure these are installed:\n```bash\npip install -r requirements.txt\n```\n\nKey packages:\n- `numpy`, `scipy`, `pandas`\n- `matplotlib`, `seaborn`\n- `scikit-learn`\n- `neo` (for .ns6 files)\n- `fastdtw` (for alignment)\n\n## 📈 Expected Output\n\n### Report Package Contents\n- **~30 Python files** (scripts, notebooks, utilities)\n- **~10 Markdown files** (documentation, guides)\n- **~30 PNG figures** (analysis visualizations)\n- **~5 CSV files** (processed data, results)\n- **3 HTML files** (interactive reports)\n\n### Generation Time\n- **Full pipeline:** ~15-20 minutes\n- **Figure generation:** ~10-15 minutes\n- **File copying:** ~1-2 minutes\n- **Report creation:** ~1 minute\n\n## 🏁 Final Checklist\n\nAfter generation, verify:\n- [ ] HTML report opens correctly in browser\n- [ ] All figures display properly\n- [ ] All analysis notebooks are included\n- [ ] README files are up to date\n- [ ] Utils directory is copied\n- [ ] Figures directory contains all plots\n\n## 📧 Contact\n\nFor questions about report generation:\n**Nader Nikbakht** -
