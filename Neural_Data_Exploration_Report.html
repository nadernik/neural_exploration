🧠 Neural Analysis

Spike Detection and Channel Selection

21 channels with clear spike activity were identified through systematic inspection, using PyWaveClus-style detection methodology.

Spike Detection Configuration:

  • Active Channels: [0, 1, 2, 3, 6, 32, 39, 40, 41, 42, 46, 49, 53, 67, 68, 73, 74, 75, 76, 77, 84]
  • Preprocessing: Bandpass filter (300-3000 Hz) + highpass (500 Hz)
  • Threshold: 5×MAD (Median Absolute Deviation)
  • Refractory Period: 20 samples (~0.67ms)

🔮 Decoding Analysis

Ridge Regression Velocity Decoder

A Ridge regression model was trained to predict 2D velocity from neural firing rates, using 21 channels in 50ms time bins.

Decoder Configuration:

  • Input Features: Firing rates from 21 channels in 50ms bins
  • Output: 2D velocity (velocity_x, velocity_y)
  • Data: 3,518 time bins across 50 trials (351.8 seconds total)
  • Regularization: α = 1000.0 (optimal from hyperparameter search)
  • Cross-validation: 5-fold CV

Decoding Challenges Identified

Key Issues:

  • Data Sparsity: Many time bins with near-zero velocity
  • Limited Directional Tuning: Channels may lack strong directional preferences
  • Temporal Resolution: 50ms bins might miss fast neural dynamics
  • Linear Assumption: Ridge regression may be insufficient for neural-velocity relationships
